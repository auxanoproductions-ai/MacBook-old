# Attention Vocabulary

Required for all Doot Labs and Auxano Productions content.
Use in titles, hooks, thumbnails, captions, scripts.

**Formula:** Intensifier + Power word + Outcome.
Intensifiers: extremely, dangerously, insanely, ridiculously, terrifyingly, unfairly.

Examples:
- How do I optimize myself? -> How do I become extremely dangerous?
- Use AI better -> Become dangerously AI-powered
- Prompt tips -> Forbidden prompts nobody talks about
